# cURL 项目

在 Runbar 左侧「cURL 项目」点「＋」，给项目命名。它不需要关联源码目录。项目、编辑内容和发送历史都保存在本机。

在「代理 HTTP」或 DevTools 的网络请求列表里，右键选「保存到 cURL 项目」，再选一个项目，也可以当场新建。请求会追加到项目末尾。点击保存提示里的「打开项目」可定位到该请求，编辑后点「发送请求」。正文需要完整缓存并且是 UTF-8 文本。抓包中本来就有的 `{{名称}}` 会按字面保存。

左栏可粘贴浏览器开发者工具复制的 Bash cURL，也支持 REST Client 风格的 HTTP 请求文本。用 `###` 分开多条请求，可在分隔符后写请求名。点一下某条请求中的内容，或用编辑区上方的选择器切换；识别成功后，编辑区下方会出现「发送请求」（⌘↩）。

```http
@base = http://127.0.0.1:8080

### 获取状态
curl '{{base}}/health' \
  --header 'Accept: application/json'

### 更新数据
POST {{base}}/items HTTP/1.1
Content-Type: application/json

{"name":"demo"}
```

正文、URL 和请求头都支持本项目内的 `@名称 = 值`、`{{名称}}` 变量。通过项目菜单可导入 UTF-8 请求文本，或将当前请求复制为 cURL。

右侧显示状态码、耗时、大小、响应头和正文。正文可切换 JSON、XML 与原始格式；图片及 macOS 支持的视频可在「预览」查看。通过右上角菜单可复制或导出响应，保存对话框默认打开「下载」目录。历史保留已发送的请求与响应，可打开旧响应、重发或将请求追加回编辑区；每个项目保留最多 50 条、64 MiB 响应数据，单个请求最多接收 16 MiB。

编辑区只发送 HTTP / HTTPS 请求，不执行 Shell。支持常见的请求方法、请求头、认证、Cookie、内联数据与表单、重定向、压缩和超时选项。需要脚本执行、从命令读取本机文件、指定输出路径等的选项会提示不支持。请求中的认证值随项目和历史保存在本机；分享请求文本前请检查这些值。
