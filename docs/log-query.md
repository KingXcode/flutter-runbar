# 日志筛选与搜索

## 使用

输出面板的「筛选」打开一个小浮层，可分别设置多个包含和排除关键词。输入关键词按回车即生效，标签的 × 直接移除，不需要再点「添加」或「应用」。匹配的是去掉 ANSI 控制码后的可见文本，按字面匹配、区分大小写，按换行分行：

- 包含为空时，显示所有未被排除的行；有包含条件时，满足任意一个即可。
- 命中任意排除词，整行隐藏。排除条件优先于包含条件。
- 每次修改自动保留当前条件，并缓存最近 128 个关键词。输入框旁的最近关键词入口可一键加入，也可从缓存删除。删除缓存不会改变正在应用的条件或已保存方案。
- 工具栏书签图标可保存整组条件；点方案名立即切换，无需再次应用。每组方案也可直接删除；同名保存更新原方案。
- 每类最多 32 个关键词，每词最多 1 KB；最多 32 组方案。关键词保留用户输入的空格。

「限定时间段」可设置起止日期和时间（精确到秒，含边界），可与关键词组合，也可随方案一起保存。筛选使用每行首次接收的时间，跨接收块的同一行仍使用最早的时间；没有可靠时间索引的内容不通过时间筛选。

勾选「时间」在正文旁显示时间侧栏，取消即隐藏，选择会保留。时间是 Runbar 接收输出的本机时间，历史索引精度为秒，一次收到的多行可以是同一时间。未知时间显示 `--:--:--`；原始磁盘窗口从一行中间开始时，不猜测该截断行的最早时间。时间侧栏不插入正文，因此不改变搜索偏移、复制内容或换行规则。

运行详情默认折叠，详细的开始 / 结束时间、退出码和完整命令按需展开；DevTools 在摘要行内使用菜单，搜索与导航各保持单行。

搜索框或 `⌘F` 搜索整份当前运行日志，覆盖磁盘中未加载到视口的内容。显示当前序号 / 总数，上下按钮或 Enter / Shift+Enter 切换，首尾循环。按字面匹配、区分大小写，不计重叠命中，搜索词最多 4 KB。

搜索始终覆盖全部日志，不受筛选影响。跳到被筛选隐藏的命中时，面板标注「搜索结果上下文 · 显示全部日志」，并提供「返回筛选结果」。清除搜索也会恢复筛选视图。原始日志文件、运行命令和已保存记录不被修改。

运行中新增输出会更新搜索总数。阅读历史位置时保留当前视口和当前命中；下一次跳转可定位新增命中。

## 内存与磁盘

不启用筛选或搜索时沿用原来的有界日志窗口：实时跟随最多 256 KB，查看完成的日志或手动定位最多 1 MB。

有查询条件时，串行后台 worker 使用 64 KB 读取块、增量 UTF-8 / ANSI 解析及有界关键词重叠区。长行的完整内容暂存在磁盘，不用无限增长的行字符串。Foundation 临时对象按块释放，取消在块之间检查；输入防抖 300 ms，旧会话 / 旧查询结果不会覆盖新查询。

接收时间 JSON 索引也按块转换成磁盘固定宽度记录，随机定位通过磁盘二分查找；内存仅保留当前窗口的时间变化标记。显示时仅绘制可见行的时间，实时追加复用已有标记，只读取新增字节和至多 4 KB 边界上下文。查询副本的时间标记按连续同时间合并，隐藏未结束行时同步回退，原始字节保持不变。

当前查询生成本地临时可见文本副本、筛选文本副本和固定宽度命中索引。每个命中仅在磁盘索引占 8 字节，内存不保存全部命中数组；序号跳转只读取对应的一个偏移。空筛选不另写筛选副本。工作内存随块大小、关键词和当前视口受限，不随文件大小或命中数线性增长；整个进程的 RSS 仍受 AppKit、系统缓存和内存压力影响，不承诺固定的进程 RSS 数值。

运行中增量处理新增原始字节，保留不完整 UTF-8 / ANSI 状态。未结束的行后续命中排除条件时，从筛选副本撤回，并使显示窗口缓存失效。切换条件或会话删除旧索引；正常退出等待扫描取消并删除当前临时文件。强制结束或崩溃后的临时文件由系统临时目录清理机制处理。首次扫描会占用磁盘空间和 I/O，空间不足会报错，原始日志保持不变。

滚动条覆盖当前全部可见内容；筛选时按筛选副本计算，搜索上下文按完整可见文本计算。页内存大小不改变整体进度。

## 验证（2026-10-26，本机）

- Xcode 完整测试：98 项，0 失败。时间相关新增测试覆盖索引增量与随机定位、跨块首接收时间、中文位置、时间区间边界、未知时间、投影回退、配置兼容，以及大量同时间日志的稀疏标记。新增测试覆盖 OR / 排除优先、隐藏行搜索、中文和 ANSI 跨块、实时未完成行撤回、百万命中随机定位、10 MB 单行、扫描中途取消及重启、截断和替换、旧配置兼容、关键词 / 方案往返保存。
- 隔离 HOME、独立 Bundle ID 的原生界面：41,199,740 字节日志，200 个命中，验证首 / 尾 / 相邻跳转和高亮；双包含词加排除词产生预期筛选结果。验证缓存与方案删除，以及重启恢复。
- 更大日志：537,840,000 字节（约 513 MiB），3,240,000 个命中，界面能直接跳到最后一个。切换并扫描大日志期间 100 次 RSS 采样（约 20 秒）为 152.9–167.8 MiB；40 MB 查询后的单次 RSS 为 168.4 MiB，大日志查询完成后的单次采样约 125.7 MiB。RSS 会波动，这些是本次观察值，并非所有设备的上限或速度保证。
- 真正的进程输出集成验证：搜索时暂停跟随，新增输出后总数由 1 自动变 2，当前位置仍为 1；下一结果可见新增行。测试命令正常完成，界面更新状态；正常退出后打开过的索引目录已删除。

测试只使用自建日志和测试命令，未读取或改写用户运行记录。

- 新界面隔离验证：逐行时间显示 / 隐藏、浮层内回车即时筛选、一键切换时间段方案，确认指定 16:02:00–16:03:00 区间的最早一行为对应时间的 ROW12000。
